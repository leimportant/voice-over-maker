# Voice Over Maker

Streamlit app untuk membuat voice over Bahasa Indonesia dari rekaman suara
sendiri atau audio referensi yang Anda punya izin untuk gunakan.

## Menjalankan aplikasi

```powershell
python -m pip install -r requirements.txt
streamlit run main.py
```

Tempel script Bahasa Indonesia, atur kecepatan dan jeda antar bagian, lalu
generate dan dengarkan hasilnya sebelum mengunduh file WAV. Aplikasi memproses
teks panjang secara bertahap agar generasi lebih stabil.
